Findings:

1. **Fixed: `next dev` rewrote `AGENTS.md`.** Next.js 16.4 appends a generated block to the authoritative agent rules on every dev start, and the block's text recommends committing it. It was not adopted. `AGENTS.md` was restored from HEAD and `agentRules: false` was set in `next.config.ts`. A repeat dev start left `AGENTS.md` unchanged.
2. **Open: hosted development has no Phase 4/5 tables.** A read-only transaction through the pooler as `myfarm_runtime` lists no accounting, harvest, stock or production-event tables. Money and inventory workflows cannot work against the local `.env.local` database until P4-C2/P5-C1 are applied. This is inferred from the table list; no signed-in hosted page was opened. Applying it needs separate authorization, a verified backup and an owner-role connection. The runtime role cannot run DDL, and the direct host resolves only to IPv6, which gives P1001 from this machine.
3. **Not a code defect:** the logged `FoundationError: UNAVAILABLE` lines come from a test that deliberately simulates provider failure, and that test passes.
4. **Open: commit `34cd4aa` is local only.** It is documentation-only and not pushed, so hosted run 40783651036 on `f999449` remains the latest hosted result.

## T001 scope

Adds `src/modules/farm-activities/domain/catalog.ts`, `contracts/catalog.ts` and `tests/unit/farm-activities-catalog.test.ts`. It reuses the existing enterprise workflow registry and `FoundationError`. No dependency, migration, route, UI or hosted change. The application does not import the module yet, so runtime behavior is unchanged until T002.

The catalog keeps all 12 values: the 11 in R001 plus Cleaning, which R003 requires. Rules follow the workflow registry rather than enterprise or crop names:

| Scope | Available |
|---|---|
| Crop | Planting, irrigation, weeding, spraying, fertilizing, harvesting, pruning, inspection |
| Poultry | Vaccination, feeding, cleaning, inspection |
| No enterprise (farm-level) | Every value except milking |
| Dairy, livestock, fish, other | None, reason given |
| Milking | Kept in the catalog, unavailable everywhere until a dairy workflow exists |

These applicability rules are an engineering interpretation awaiting owner review under D-P06-006.
