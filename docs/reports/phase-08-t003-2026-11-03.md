Adds the page `/farms/{farmId}/accounting/how-the-farm-is-doing` and `src/components/analytics/dashboard.tsx`, linked from the farm page and the money navigation. It reuses the accounting shell, report filters and money formatting, and calculates nothing itself. `ReportFilters` gains an optional `before` slot for the season choice.

The screen shows money earned, money spent, recorded surplus and margin per currency, then enterprises with the highest named in words. It names amounts linked to no enterprise or no season. A missing margin says why, and an empty view explains itself instead of showing zeros. The opening text says this is not full profit, and no figure carries a profit label.

**Offline (D-P08-008):** a signed-in page opened with no connection already falls back to the offline shell. The shell now always says that this screen needs a connection. It does not depend on `navigator.onLine`, because that stays true when a phone has a network but cannot reach MyFarm; the first version did depend on it, and the browser test caught this.
