## Scope and authorization

The owner replied "approved" to both pending initial access and card-definition requests on 2026-11-21. D-P14-002 records the approved subset. This task implements MYF-P14-T001 only, on working-tree base `79b1e20f9e94be142433be384424ee634829ae8b`. Phase 13's accepted conditional closeout is preserved. No Phase 14 server route, executable grant, dashboard UI, registration, media or offline queue is delivered here.

`src/modules/extension-officers/contracts/dashboard.ts` defines strict Zod contracts for trusted current assignment and dashboard facts. Grants are named, scoped to tenant/farm/farmer, tied to active current owner facts, explicitly permissioned and bounded by their actual validity timestamps. Nullable expiry does not impose a retention or expiry period. The repository must verify the owner's active ownership and consent; these facts are not a browser authentication DTO or an approved persistence schema.

`src/modules/extension-officers/domain/dashboard.ts` requires an active account and current AGENT membership, then a matching current explicit assignment. Role or organization membership alone never confers farm access. `assertOfficerAssignment` binds the permission to the requested tenant/farm/farmer and named officer. Missing/foreign/future/expired/revoked grants or changed/inactive owners deny access. Any non-null revocation denies immediately. Finance, export, unassigned search and assisted registration are unsupported actions.

The pure projection counts distinct currently permitted farmers across multiple farms; the officer's planned/completed visits scheduled today in the existing Africa/Kampala farm calendar, excluding cancelled visits; open follow-ups due today or overdue; and explicitly flagged unresolved problems with a matching permitted visit parent. Each card requires its relevant granted capability plus dashboard access. No diagnosis is inferred. The source's 248/12/8/5 illustration is never an application total.

Identical joined rows count once; conflicting identities or conflicting farmer ownership for the same farm fail with CONFLICT. Bounded fact arrays and mandatory coverage prevent accidental authoritative totals from incomplete/paginated facts: PARTIAL returns null totals, not zero. T002 must perform current, consistent authorization and scoped reads before constructing these facts. Parsing a DTO is not proof that its ownership or role claims are true.
