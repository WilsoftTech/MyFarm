The model is `ProductionActivity` because the enum `FarmActivity` already exists. Status stores the lifecycle only; today, upcoming and missed will derive from the due date in T004.

Security: current membership is rechecked inside the write, foreign parents return FORBIDDEN and leave no receipt, and retries replay one activity while changed retries conflict. Optional parents use single-column keys, so the database policy binds them to the activity's farm. The runtime role has SELECT and INSERT only; browser roles have nothing and RLS is enabled.
