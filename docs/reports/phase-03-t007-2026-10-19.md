## Rules and limits

- **Starting quantity:** a whole number from 0 to 2,147,483,647 (the PostgreSQL `integer` range). Forms may send digit strings (leading zeros normalize, e.g. `0100` → 100), and APIs may send safe integers. Fractions (including `1.0` as text), signs, exponents, separators, blanks, non-finite and oversized values fail. Negative zero becomes 0.
- **Batch label:** required, at most 120 characters after trimming and collapsing whitespace. The farmer's capitalization is kept for display. The identity key also applies Unicode NFC and lowercases, so `Batch  #004` and `batch #004` are the same batch, while `Batch #04`, `Batch 004` and `Batch-004` are distinct. Uniqueness per farm across all statuses is a T008 repository/database obligation (duplicate → CONFLICT); the pure rule cannot see other batches.
- **Parents:** the enterprise must be on the authorized farm and tenant (otherwise FORBIDDEN), be POULTRY (otherwise INVALID_INPUT) and be ACTIVE (otherwise CONFLICT). The catalog entry must be the requested animal type and active. Animal type names are data, not code.
- **Acquisition date:** a real `YYYY-MM-DD` calendar date with no future-date limit, matching crop planting dates.
- **Purpose:** one of EGGS, MEAT, DUAL_PURPOSE, BREEDING. No Other option, as decided.
- **Current quantity provenance:** in Phase 3 the current count equals the starting count with source `STARTING_COUNT`. Phase 5 movements (purchases, mortality, sales) will add movement-derived sources. The current count is never accepted from a client.

## Repository and persistence boundary

The `PoultryBatchRepository` port defines the animal-type catalog page, scoped batch detail and list reads, and a start command. T008 obligations are:
- recheck current authorization inside the write transaction
- resolve the POULTRY enterprise and active catalog entry, then reuse `assertPoultryBatchStart`
- enforce the farm-wide label key across all statuses
- persist the row and audit receipt atomically, with identical-retry replay and conflict on changed payloads or farm

T008 must also add the minimal additive schema with the approved animal-type seeds (Chicken, Duck, Turkey, Guinea fowl), same-farm composite relationships, integer/date/label checks, deny-by-default RLS and runtime grants. It must verify fresh and upgrade migrations, duplicate labels under concurrency, retries, rollback and cross-scope access on an isolated database. None of this is implemented or claimed here.
