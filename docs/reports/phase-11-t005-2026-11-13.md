## What T005 adds

**Where each tool reads.** `FarmSources` is the one place the tools read from. Every read goes through the owning module's own authorized service, so the asker's membership is checked again for every tool:

| Question type | Service |
|---|---|
| Highest profit, explain profit, summary, report | `farmScreen` (Phase 8): dashboard, cost groups and reconciliation |
| Compare seasons | `dashboard` twice: the chosen season, then the one before it |
| Ask records | Money records list (Phase 4), newest first |
| Unusual costs | Alerts feed (Phase 10). This counts against the Alerts limit (D-P10-009) |
| Upcoming tasks | Activities today, upcoming and missed (Phase 6) |

The assistant never queries records itself, never writes and never makes a file. `sourcesFrom` (in `application/sources.ts`) is one wiring shared by the app and the tests. Its mappers keep only the fields a tool uses: a record's counterparty and a task's worker and notes never reach the assistant.

**The fake** now recognizes all ten intents (the seven types, highest profit, advice and unsupported) with ordered keywords. The question corpus in `tests/unit/ai-assistant-intents.test.ts` has 3 to 4 phrasings for each. A real provider will be judged on the same list before farmers see it.

**Migration `202611130001_assistant_question_types`** adds the seven types to the question-type list. It is additive: values can only be added.

The "what can be asked" sentence now lists every type.

## Tests

**Integration** (`tests/integration/ai-assistant-service.test.ts`, 4 new, 17 in all), on real PostgreSQL under the restricted role. The data: season 2026A, an earlier season 2025B, two scheduled tasks, and the Phase 10 source-example batch (eggs down, feed cost per bird up):

| Test | Shows |
|---|---|
| Seven types | Each question reaches its own tool, with provenance. "For 2026A, money earned was UGX 3000000 and money spent was UGX 1280000, so the recorded surplus is UGX 1720000." "The surplus is 57.3% of the money earned." "The recorded surplus was UGX 1720000 in 2026A and UGX 400000 in 2025B: a change of UGX 1320000." One cost alert with its feed figures; work due and work missed; the latest records |
| Stale context | An answer keeps the figures it was given. After a new sale, asking again shows the new surplus, and the earlier answer still shows the old one |
| Refused exports | A report creates no export receipt and no export count, and contains no file name or link. A member removed from the farm is refused on every type and on the list |
| Provider outage | For every type, a failing provider gives MyFarm's own answer, word for word the same as the fake's |

**Unit** (`tests/unit/ai-assistant-intents.test.ts`, 5 tests):
- **Corpus:** every intent is covered and every question placed; an injected instruction changes only which question is answered, never the farm.
- **Cost alerts:** only open alerts of the five cost rules (cleared ones and other rules left out), with what could not be judged.
- **Fields:** counterparty, worker and notes are dropped.
- **Reading order and limits:** today, upcoming, then missed, each bounded.
