Adds the hand-written service worker `public/sw.js`, the static `/offline` shell, signed-in phone preparation (`OfflineSetup`), the storage panel, and a sign-out form that clears cached farm data and keeps unsent entries. The worker stores only built assets and the data-free shell. A unit test runs the real script and checks its caching rules against the domain policy. `/offline` and `/sw.js` skip the session proxy, so they keep working when the auth provider is unreachable.

Browser tests stop a dedicated app server to create real disconnection, because Playwright's offline emulation also blocks navigations that a service worker should answer. This also covers the case where the phone reports a connection but nothing responds. The auth test fixture gains a logout route.

PASS on desktop and mobile: the shell cold-starts in a new page with the server stopped; a signed-in page falls back to the shell; the cache holds only the shell and built assets; the app works again after reconnecting; persistence and low-space warnings are visible; a phone with no prepared account says so; deleting the local database leaves a working empty shell; sign-out clears cached data, keeps unsent entries and forgets the account. Typecheck, lint, boundaries and fixture build pass.

MYF-P07-AC001 stays open until T006, because a real quota failure needs a local entry form to fail. Worker upgrades with entries waiting are tested at T012.

The browser test found a real race, now fixed with a regression test: if the phone was still preparing when a farmer signed out, the late answer restored the account pointer after sign-out cleared it. Preparation now carries a generation, and an answer from before a sign-out is ignored.
