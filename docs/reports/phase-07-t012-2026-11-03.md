Adds real-browser journeys for reconnect, retry and conflict, and shared browser test helpers. Opening the app and reconnecting now send immediately rather than waiting out a retry delay, which the architecture requires and these tests found missing. The periodic timer still respects the delay.

**MYF-P07-AC004 is verified locally.** PASS on desktop and mobile with real server stops:

- **The source's critical test:** expense recorded offline, server commits, the answer is lost, then reconnect: one transaction and the entry shows Sent.
- **Two tabs** sending at once create one transaction.
- **Two phones** finishing one task: one is accepted and the other asks for review.
- **Ended session:** entries stay queued and the screen asks the farmer to sign in.
- **Revoked member:** entries are refused, kept visible and downloadable, and create no record.
- **Expired and interrupted pull:** saved copies and unsent entries are kept, and a later pull completes.
- **Support limits:** entries older than 14 days warn clearly and still send once; at 500 unsent entries a new save says not saved and keeps the input.
- **Shared phone:** a second account sees none of the first account's farms or entries; the first account's entry stays hidden and sends when that account signs in again.
- **Service worker replaced** while an entry waits: the entry stays intact and sends.

**Simulated, not measured:** entry age is set by moving its stored date back, so 14 real days offline have not elapsed. 500 entries are seeded directly rather than typed. There is no local schema upgrade to test yet, because only version 1 exists; the rule that an upgrade must keep the queue applies to the first version 2.

Real low-cost Android behavior, including browser eviction and true background conditions, remains unmeasured and is a closure condition.
