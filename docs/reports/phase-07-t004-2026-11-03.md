Adds `domain/commands.ts` and `contracts/commands.ts`: the offline operations, new outbox entries, photo validation that reads the bytes rather than trusting a declared type, the bounded pull walk, and pull cursors. Each command validates with the existing server schema, so the phone and server cannot disagree about what is valid, and field errors appear before anything is saved. `requestId` is the `clientMutationId`, so existing receipts apply.

`COMPLETE_ACTIVITY` is added beyond the source's list because it is the offline action that can hit a stale version. Record activity and create task both map to farm activities: one is already done, the other is due later. A pull cursor grants nothing, because every page is authorized again; it expires after 24 hours. Cached data is limited to 200 rows per section and 50 farms, which is an engineering choice for low-cost phones and open to owner review.
