Adds the Sync Center to the offline screen: automatic sending on opening, on reconnecting and every minute in the foreground, a Send now button that skips any retry wait, a status per entry, Fix details for refused entries, conflict review, confirmed Discard, and the unencrypted download of unsent entries required by D-P07-005. Signed-in pages now send leftovers and refresh saved copies. Cached tasks can be marked done offline, carrying the version the farmer saw. Background delivery is not assumed.

**MYF-P07-AC003 is verified locally.** PASS on desktop and mobile with real servers: entries saved with the server stopped send on reconnecting, with a photo uploaded after its parent and its local copy then removed; a send abandoned by a crash goes again and creates one record; a refused entry keeps its details, holds its child, and sends after fixing under a new ID; a stale edit asks for review and never overwrites the newer change; a passing server failure counts an attempt and retries; the download holds readable unsent details and says it is not encrypted.

`LOCAL_ONLY` is defined but entries do not rest in it, because validation runs before saving and a saved entry starts as `PENDING`. An edit of a finished record cannot be retried, so only Discard is offered; retrying on the latest version appears only when the record is still open. Multi-tab behavior relies on Web Locks, and leases and receipts cover browsers without it; the replay proof follows at T011.

The browser tests also found a small real bug, now fixed: "Nothing is waiting to send" could flash before the queue had loaded. It now shows a checking message until the queue is read.
