## What T008 adds

- **Contradictory sources in the service.** Every money question now applies the farm screen's own reconciliation: highest profit, profit, summary, report and comparing seasons. Comparing seasons now reads the farm screen for both seasons, so both are checked. A currency whose checks fail has no conclusion. Its plain answer says what disagrees, and no provider is asked at all, so no provider can state those figures.
- **A rule against parroting the question** (`ECHOES_QUESTION`). An explanation that repeats six or more words in a row of the farmer's question is refused. Without it, an instruction hidden in a question could be repeated in plain words, which the other rules (digits, links, refs, advice, certainty) would not catch. Short shared phrases such as "the most money" stay allowed.
- **A read-only `evidence` method on the service.** It returns what a question type would be answered from, worked out afresh. It is authorized like a question, stores nothing, counts against no limit and calls no provider. The groundedness evaluation and the T010 audit use it as the independent reference.
