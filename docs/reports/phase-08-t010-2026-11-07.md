## Changes

**Reconciliation** (`domain/reconcile.ts`, the spec's `ReconcileDashboard`). For each currency in one view it checks, by independent paths, that:

| Check | Rule |
|---|---|
| `SURPLUS` | Recorded surplus = money earned − money spent |
| `REVENUE_ADDS_UP` | Each enterprise's revenue + revenue linked to no enterprise = money earned |
| `COSTS_ADD_UP` | Each enterprise's costs + costs linked to no enterprise = money spent |
| `COST_GROUPS_ADD_UP` | Labour + inputs + other costs = money spent, and no cost group in a currency the dashboard lost |
| `CROP_MONEY_MATCHES` | Each crop line's costs and revenue = that enterprise's line on the dashboard |

A failure names the check, currency, expected and found amounts. It reads results only and never corrects anything. A malformed figure is refused rather than read as 0.

**Scope guard** (`tests/unit/mvp-scope.test.ts`). It fails if a route, module or component for AI, voice, markets, wallets, lending or billing appears, if an AI, payment-provider or messaging package is installed, or if code reads a secret for one. Phase 4's `payments` (settling sales and purchases) is allowed by name.

No schema change.
