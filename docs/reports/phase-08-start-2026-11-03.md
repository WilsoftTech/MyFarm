## Decisions

| Decision | Approved rule |
|---|---|
| D-P08-002 Profit label (Q10) | Enterprises show gross margin. The farm shows recorded surplus, which deducts every recognized cost. Shared costs are not allocated. Screens say depreciation and loan costs are not included. Nothing is called net profit. |
| D-P08-003 Batch costs | Expenses and purchases gain an optional poultry batch through an additive schema change, online and offline. Unlinked costs are shown as such. |
| D-P08-004 Stock value (Q12) | A labelled estimate at the item's last sale price not reversed, with the sale date, kept out of surplus and margin. Not available for an item never sold. |
| D-P08-005 Crop formulas (Q17) | Area converts exactly to acres, counting each cycle once. Yield uses gross kg. Cost per kg and break-even price use kg after loss. |
| D-P08-006 Bird formulas (Q17) | Mortality, cost per bird and revenue per bird divide by birds started: starting quantity plus later purchases. |
| D-P08-007 Missing values and trends (Q17) | A zero or missing denominator or baseline is "Not available" with a reason, never 0. Trends compare like with like, in the same currency and unit, and warn about unlinked costs. |
| D-P08-008 Season scope and freshness (Q17) | A season counts only records linked to it. Figures are calculated live, so no snapshot tables. With no connection, the dashboard says so and points to offline work. |

## Implementation plan

**Module.** `src/modules/analytics-profitability/` follows the existing layers. It reuses Phase 4 recognition and gross margin, so the dashboard and the existing report cannot disagree. No new dependency is planned: exact arithmetic already exists in `money.ts` and BigInt.

**Tables not built.** The specification proposes `MetricSnapshot` and `ReportDefinition`. D-P08-008 makes figures live, and formulas live in tested code, so neither is needed. Large histories (P4-C3) are measured at T005 and T013 rather than assumed to be a problem.

**Schema.** Only T004 needs one, for the batch link. It must extend the `AccountingRecord` insert policy, the record forms and the offline payload. Existing offline entries lack the field, so it stays optional in replay. Hosted use needs the owner's separate step.

**Cost groups.** The source asks for labour and input cost. Which categories count is not yet decided, and a source guard forbids catalog names in code, so T004 will classify categories in reference data after owner approval. Proposal: labour is Labour; inputs are Seeds, Feed, Fertilizer, Veterinary, Medication and Pesticides.

**Screens.** A new "How the farm is doing" page reuses the accounting shell and report parts. T006 adds per-acre, per-kg and per-bird figures, and T009 adds trends.

## Risks

- **Linked data:** per-season and per-batch figures are only as complete as the farmer's links. D-P08-003 and D-P08-008 show unlinked amounts rather than hide them, but a farmer who links nothing sees little in a season view. The field pilot should check this.
- **Label:** "recorded surplus" must be understood by real farmers. Wording needs validating at the Phase 9 pilot.
- **Volume:** live calculation reads every record in scope. Phase 4 expected small histories, and this has not been measured with long ones.
- **Windows-only local audits:** the Phase 7 hosted failure could not occur on Windows, so closing Phase 8 needs a hosted run as well as a local audit.
